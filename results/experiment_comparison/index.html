Concept Drift in CNP Fraud Detection

Static vs. adaptive model performance under controlled concept-drift scenarios

Purpose: Compare how static and adaptive fraud models behave across controlled concept-drift phases and determine whether adaptation helps as transaction behavior changes.

Concept drift: the relationship between transaction characteristics and fraud changes over time, so models trained on earlier behavior may become less effective.

Dataset

CreditTransAct
Source transaction dataset used by the project.

CNP transaction stream
Card-Not-Present transactions used for streaming fraud detection.

500,000 warm-up rows
Historical rows used before stream evaluation.

1.5M evaluation rows
Transactions evaluated across the controlled-drift stream.

50,000 rows per batch
Sequential evaluation batch size.

30 evaluation batches
Evaluation stream processed across 30 sequential batches.

7-batch label delay
Fraud labels become available seven batches after prediction.

Why was Static Random Forest already extremely strong?

The initial evaluation showed near-perfect pre-drift performance because the data contained highly discriminative fraud-related attributes.

Follow-up feature audit and ablation work found no evidence that this strength came from direct target leakage.

Why did Static Random Forest improve after the original drift?

The original drift increased fraud-versus-legitimate separation across several fraud-related features, making fraud easier rather than harder to distinguish.

Static RF Recall: 0.993 → 0.996 → 1.000

Other models also remained near their pre-drift performance, leaving limited degradation for adaptive models to recover from.

Why camouflage?

The original drift made fraud easier to distinguish. Camouflage drift instead moves fraudulent behavior closer to legitimate behavior, creating meaningful performance degradation.

This allows us to evaluate whether drift detection and adaptive retraining can recover lost performance.

What changed under camouflage drift?

Camouflage moves selected fraudulent feature distributions toward legitimate behavior, reducing class separation and creating meaningful performance degradation.

Unlike the original drift, the revised scenario produces positive relative performance loss. The frozen models experience greater degradation, while ADWIN and DDM use drift detection and adaptive retraining to partially recover performance.

Results Between the Two Evaluations

Key Finding: The original drift did not create meaningful degradation. Under camouflage drift, the frozen Random Forest degraded substantially. After detector-triggered retraining, ADWIN and DDM achieved higher fully-drifted Recall and F1 than the frozen baseline, showing partial recovery under concept drift.
